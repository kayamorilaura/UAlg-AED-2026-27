# TP2 — Casos de teste

## Estrutura da lista

- [ ] Lista inicialmente vazia (`estaVazia()` retorna `true`).
- [ ] Inserir uma pessoa e verificar que o tamanho passa para 1.
- [ ] Inserir tres pessoas e confirmar a ordem de apresentacao.
- [ ] Rejeitar a insercao de `null`.

## Leitura e escrita (apos confirmar o formato)

- [ ] Ficheiro vazio.
- [ ] Ficheiro com um registo.
- [ ] Registos repetidos.
- [ ] Ficheiro de texto malformado.
- [ ] Ficheiro binario incompleto.
- [ ] Gravar e reler, preservando os registos.

## Divisao (apos definir as regras)

- [ ] Preservar a ordem relativa nas duas listas.
- [ ] Tratar nomes ambiguos ou sem classificacao conforme regra documentada.
- [ ] Nao perder nem duplicar registos involuntariamente.
